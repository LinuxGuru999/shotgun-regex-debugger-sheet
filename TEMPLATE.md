# Regex Debugger Sheet

A one-page regex reference with common patterns

## Overview
A copy-ready template. Duplicate it, fill the sections, and delete the instructions.

## Template

```markdown
# [Title]

Date: [YYYY-MM-DD]
Owner: [name]

## Context
[Why this exists]

## Key points
- [point 1]
- [point 2]
- [point 3]

## Decisions
| Decision | Owner | Date |
| --- | --- | --- |
|  |  |  |

## Next actions
- [ ] [action] — [owner] — [due]

## Notes
[Anything worth keeping]
```

## Tips
- Keep sections short; empty sections are fine.
- Review weekly and archive what is no longer relevant.
