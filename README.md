# Regex Debugger Sheet

A one-page regex reference with common patterns

## Overview
Regex Debugger Sheet is a compact one-page reference for developers who need common regex syntax, anchors, quantifiers, and flags at a glance. It includes 16 copy-paste patterns and a flag cheat sheet to speed up everyday matching tasks. It is designed as a quick lookup aid, not a full regex course or engine-specific guarantee.

## Use cases
- You are debugging a failing validation rule and need to quickly check anchor or quantifier syntax.
- You are writing a new input pattern and want a safe starting template before customizing it.
- You are onboarding a junior developer and need a shared, concise regex reference during code review.

## How to use
1. Download the file after purchase.
2. Open it in your PDF viewer or browser.
3. Copy the relevant pattern or flag notation into your regex tool or code.

## What is included
- Anchors and quantifiers
- 16 copy-paste patterns
- Flag cheat sheet
